Nombre de proyecto: Gestor de contactos
Conectamos personas, organizamos información y transformamos ideas en soluciones: un gestor de contactos

funcionalidades:
1.Agregar contactos(Permitir registrar información básica como: Nombre, Apellido, Número de teléfono, Correo electrónico, Dirección)

2.Buscar y consultar contactos
Incluir una barra de búsqueda para encontrar contactos rápidamente por nombre, apellido o número de teléfono.

3.Editar y eliminar contactos
El usuario podrá modificar los datos de un contacto o eliminarlo cuando ya no lo necesite.

4.Marcar contactos como favoritos
Permitir seleccionar contactos importantes como favoritos para acceder a ellos de forma rápida desde una sección especial.
