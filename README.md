Conectamos personas, organizamos información y transformamos ideas en soluciones: un gestor de contactos creado por estudiantes de Ingeniería de Sistemas.

Funcionalidades:
Agregar contactos
1. Permitir registrar información básica como: Nombre, Apellido, Número de teléfono, Correo electrónico, Dirección
2. Editar y eliminar contactos
3. Marcar contactos como favoritos
